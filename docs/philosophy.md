# Philosophy

Pragmatic Agent Engineering is not anti-complexity. It is anti-**unproven complexity escalation**.

## Generation Cost vs. Maintenance Cost

AI dramatically reduces the cost of writing complex code. It does not equally reduce the human cost of understanding, reviewing, debugging, migrating, operating, and maintaining that code.

The stronger coding agents become, the more valuable engineering restraint becomes.

## Minimum Sufficient Complexity

The simplest solution is not always correct, and the most powerful solution is not always worth its cost.

The target is:

> **Use the minimum complexity sufficient for real requirements and hard constraints.**

## Complexity Burden of Proof

Complexity should not be assumed correct until someone proves it excessive. Meaningful complexity should explain the real problem it solves and why its long-term cost is justified.

## Governance Must Pay Rent Too

This project will not fight excessive code governance by creating excessive rule governance.

If a new core rule cannot demonstrate a repeated real problem that existing rules do not cover, it should not enter Core.
