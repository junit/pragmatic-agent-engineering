# Architecture Reviews

This directory contains architecture reviews using Pragmatic Agent Engineering.

Useful review dimensions include:

- real requirement and success criteria;
- necessary complexity;
- complexity without evidence;
- source of truth;
- failure model;
- complexity warning signs;
- removable or mergeable mechanisms;
- verification strategy.

A review should not ask only “What else have we missed?” It should also ask:

> **What can we remove now?**
